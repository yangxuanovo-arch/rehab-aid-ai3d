# 03｜数字技术应用路线

本页说明设计路线；具体库、模型、阈值和接口以最终提交版本的代码与运行证据为准。

**草图＋文字 → 意图解析 → 参数规范化与校验 → 模板几何生成 → 网格检查与导出 → 切片／结构仿真 → 证据归档**

| 环节 | 输入／处理 | 输出与失败处理 |
| --- | --- | --- |
| 意图解析 | 利用草图的外形线索和文字约束，确定原型类别与尺寸建议 | 产生结构化设计参数；若使用人工选择、规则回退或仅解析文字，记录实际采用的路径，不归因于图像 AI |
| 参数规范化 | 统一为毫米，检查必填项、取值范围及配合关系 | 缺失或冲突参数提示修正；区分用户确认值与建议或默认值 |
| 参数化建模 | 利用类别模板构造握持体、通道／槽位或开口壳体 | 三维网格与可导出模型；预览与导出应对应同一份确认参数 |
| 几何与结构检查 | 核对边界尺寸、网格非空与封闭性；按实现核查连通性、局部薄弱区域等 | 分项记录通过、未通过或未运行；列明采用的算法及阈值，不由包围盒推断局部精度 |
| 切片验证 | 将同版模型送入指定切片器；固定机型、喷嘴、材料配置、方向和支撑策略 | 记录切片程序状态、输出路径与警告；打印时间和材料量为切片估算 |
| 结构仿真 | 使用声明的几何、材性、约束、载荷与求解方法 | 记录收敛状态与实际可计算的指标；简化力学或数值代理不能写成有限元结果 |

## 仿真可复现信息

为同一案例保存模型版本与单位、材料参数及来源、支撑和受力位置、载荷量级，以及求解器或计算脚本版本。若采用有限元，另存网格类型与规模、求解收敛状态、结果图与读数位置，必要时做网格敏感性检查。若仅采用梁模型等简化方法，则给出其假设、计算指标和适用范围，并标记为工程估算，不声称验证人体接触或真实服役条件。

## AI 使用口径

只描述最终版本实际调用的输入与模型能力。记录草图是否参与本次参数提取、哪些参数由用户修改、哪些来自默认或回退；若结果由规则生成，就标明基线或回退。没有对照实验时，不声称 AI 提升了准确率、成功率或效率。
