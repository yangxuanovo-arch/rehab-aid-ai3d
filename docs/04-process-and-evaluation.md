# 04｜设计任务与流程展示

## 任务与证据对应

| 任务 | 操作过程 | 留存证据 |
| --- | --- | --- |
| 准备案例 | 自绘草图与文字配对；覆盖三类辅具，提前固定预期类别、关键尺寸与异常样例 | 原始草图、提示词、案例编号、预期值 |
| 生成与复核 | 记录解析路径、确认最终参数；生成模型后复核关键尺寸 | 参数记录、对应模型、实际尺寸、检查报告 |
| 数字制造验证 | 用固定配置对模型切片；对选取的代表模型执行结构仿真或简化力学分析 | 切片日志、路径预览、仿真输入和结果 |
| 展示与复现 | 用匿名窗口运行一条完整路径，展示至少一条异常输入；核对可下载文件属于同一版本 | 成片、带案例编号的截图、版本和访问入口 |

## 基准测试口径

- **样本。** 分开记录正常生成组与异常拦截组。正常组按三类分层，覆盖典型参数和可接受的边界值；异常组包含越界尺寸、缺少必要输入等，记录是否正确拒绝。案例允许使用真实运行的合成输入，但必须注明不是临床或患者数据。
- **时间。** 明确计时起止和是否包含网络、预览、切片与仿真；同时记录运行设备、软件版本、冷启动与预热状态、重试方式。耗时报中位数与 P95 时，注明样本量、统计范围和分位数算法；未计入的失败耗时另列。
- **生成。** 正常组成功率的分母是全部预先选定的尝试，不删除失败项。成功需满足预先定义的产物和检查条件；分别给出三类、总体的成功数与尝试数。异常组另报正确拦截数／异常尝试数。
- **切片。** 单列实际尝试数、通过数与未运行数；执行成功且生成非空路径时，仍需保留配置和警告。选取代表案例切片时，不把通过比例推广到未切片案例。
- **仿真。** 逐案例报告工况与结果，只在预先定义的判定规则内作比较；求解失败保留原记录。未运行不能标为通过；仿真指标不替代实体或临床试验。

## 结果与证据登记

本节只记可回溯的测量。**在报告和原始记录可查之前，下表不代表任何实测结果。**

| 待回填项目 | 当前状态 | 回填所需信息 |
| --- | --- | --- |
| 测试版本与环境 | 待实测记录 | 提交版本、设备、依赖版本、计时边界 |
| 生成耗时 | 待实测记录 | 分类别样本数、中位数、P95、原始计时 |
| 生成成功率 | 待实测记录 | 按类别与总体的成功数／尝试数、失败原因 |
| 异常输入 | 待实测记录 | 正确拦截数／异常尝试数、预期与实际 |
| 切片验证 | 待实测记录 | 通过数／尝试数、未运行数、配置、警告、日志与截图 |
| 结构仿真 | 待运行或证据复核 | 案例、工况、方法、结果单位、日志／结果图 |
| 实物打印与佩戴 | 本阶段不开展 | 无实体打印、佩戴或临床证据 |

每条原始记录至少能用「版本＋案例编号＋尝试编号」定位，关联输入、最终参数、各步骤状态和产物；失败要写明所在步骤。主文档、模型展示页与视频使用同一证据，不另填无法核查的百分比。
