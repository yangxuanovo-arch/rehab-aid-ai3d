# 01｜项目创意及原理说明

**作品暂名：辅形工坊——草图与文字驱动的个性化康复辅具设计。**

面向「AI3D 数实融合 全民共创」主题，作品把日常辅助需求转成可调尺寸、可检查、可供切片的三维原型，连接非专业用户的设计表达与增材制造准备。

## 项目创意

握笔、使用餐具和佩戴护具是三种不同的设计任务，但都有同一个难点：草图能画出大致形状，却不包含可靠的绝对尺寸和制造约束。只凭通用成品难以试探不同尺寸；从零建模则要求用户懂三维软件。本项目让用户用草图说明形状与方向，用文字和显式尺寸说明用途及配合要求，先得到一件可核对的原型，再决定是否改变参数并重新生成。

| 辅具类别 | 设计任务 | 需要显式确认的尺寸举例 |
| --- | --- | --- |
| 握笔器 | 扩大握持外形并给笔杆留出通道 | 笔杆直径、握持外形长度 |
| 餐具手柄 | 扩大握持外形并匹配已有餐具柄 | 配合部位尺寸、握持段长度 |
| 矫形护具 | 展示开口壳体的尺寸调节及数字检查 | 壳体长度、截面尺度、开口方向和壁厚 |

三类辅具是同一件软件作品的三个设计案例，不是三件独立参赛作品。护具仅为矫形护具的形态与制造准备演示，不用于个体诊断、矫正或实际佩戴；项目不声称具有临床效果。餐具手柄案例也不提供食品接触适用性结论。

## 工作原理

1. **给出设计意图。** 草图描述相对外形，文字表达类别、用途和约束。没有刻度的草图不作为毫米测量来源，绝对尺寸以明确填写或确认的参数为准；默认值不能冒充人体测量值。
2. **限定可生成范围。** AI 用于理解输入并辅助形成可编辑的设计参数，三类模板分别定义握持体、配合槽或开口壳体等结构。无法解释的输入、参数冲突与超范围尺寸应提示用户核对，不靠生成一张逼真的外观图来掩盖错误。
3. **从几何走到制造准备。** 按参数生成三维网格，核对选定尺寸、网格与结构约束，再使用指定的切片配置和简化仿真检验数字原型。保留输入、参数、版本及验证记录，让评委能追溯同一次生成。

**验证边界：** 没有实体打印条件。目标是输出可供切片的数字原型；「网格检查通过」「指定配置切片通过」「指定工况仿真结果」是不同结论，不等于实体已打印、人体适配、强度认证或可直接佩戴。
