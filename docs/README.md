## 送审前需要补齐

1. 核对当届官方及赛区通知，确认报名资格、赛道、截止时刻和文件格式；指导老师暂空，不填虚构姓名。
2. 固定演示版本，在无痕窗口打开免登录链接，完成三类生成与下载，再登记入口及备用离线材料。
3. 按[证据登记](04-process-and-evaluation.md#结果与证据登记)回填实际运行数据；没有完成的一律按「未运行」或「未开展」标注。
4. 将成片、三类模型、展示图与证据链接到相应材料，检查匿名访问和版本一致性后再提交。

**验证边界：** 只做数字切片和仿真，不做实体打印、实际佩戴或临床验证。模型为演示原型，不是可直接用于患者的医疗产品。
