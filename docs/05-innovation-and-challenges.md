# 05｜项目创新点及技术难点

## 创新点

1. **把意图理解与确定性几何分开。** 输入帮助确定类别和设计参数，参数化模板限制输出空间；用户修正一个毫米量值即可重建，而不需要重新绘制整张草图。以修改前后的参数及网格尺寸对照证明这个过程。
2. **把「能生成」和「能制造」分开。** 分别呈现网格、切片和简化仿真所能证实的内容，保留未通过与未运行。以一条失败样例展示系统如何提示用户，避免把网格预览当作打印结论。
3. **同一条管线覆盖三类配合问题。** 握笔器检查通道，餐具手柄检查配合槽，矫形护具检查开口壳体；三类输出统一追溯到输入和参数。以归档的案例和验证记录给出差异与适用范围。

这里的「创新」指本作品的流程与系统集成设计，不声称算法首创或性能领先行业。

## 技术难点与应对

| 难点 | 应对方式 | 可检验证据 |
| --- | --- | --- |
| 草图比例、语义与实际尺寸不一致 | 绝对尺寸单独确认；对来源、默认与冲突处理留痕 | 缺少尺寸、矛盾文字、同图变更单一参数的案例 |
| 模板极值可能产生退化或过薄几何 | 校验参数、分类检查，并对不能确认的情况给出未通过或未运行状态 | 边界样例、检查日志、可重新导入的模型 |
| 切片可行性依赖具体配置 | 绑定切片器版本和配置，保留路径、警告与估算值 | 同一模型与同一配置的切片记录 |
| 仿真假设不代表实际佩戴或使用 | 明确边界条件、材料模型和载荷；说明方法及简化，不扩大结论 | 仿真工况、输出与局限说明 |
| AI 解析与规则回退难以区分 | 记录每个案例的解析路径和草图是否参与 | 输入、最终参数、路径标签；若做对照，使用相同案例和成功口径 |
